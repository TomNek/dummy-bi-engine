# Security Policy

## Reporting a vulnerability

Please do not open public issues for suspected security vulnerabilities.

Preferred: open a **private GitHub Security Advisory** for this repository.
If that is not available, open a GitHub issue with minimal detail and request a private channel.

If private reporting is required and GitHub advisories are unavailable,
please contact the repository owner.

## Supported versions

This project is currently in alpha; security fixes may be released as patch bumps.
