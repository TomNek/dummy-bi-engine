# AI-Assisted Development Policy

This repository may be developed using AI-assisted tooling.

## What this means

- AI tools may be used to draft code, tests, and documentation.
- Changes must remain deterministic, test-covered, and consistent with `project_plan.md` and `instructions.md`.

## Provenance rules

Contributors must not:
- paste code from restricted/copyrighted sources
- introduce third-party code incompatible with the repo’s `LICENSE`

## Terminology / claims

- This project is DAX-inspired and aims to compile DAX expressions into DuckDB SQL.
- It is not an official Microsoft product and does not claim any Microsoft compatibility guarantee.
